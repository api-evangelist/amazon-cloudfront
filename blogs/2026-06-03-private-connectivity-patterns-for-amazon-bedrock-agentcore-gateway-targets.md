Outlines four private connectivity patterns for routing AgentCore Gateway traffic without traversing the public internet, including MCP servers via VPC Lattice private endpoints, REST APIs using private endpoints, Regional REST API Gateway targets via VPC Link, and Lambda functions using Hyperplane ENIs. Also covers on-premises, multi-cloud, and multi-VPC configurations using Direct Connect, Site-to-Site VPN, and Transit Gateway.
